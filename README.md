# Java Exercícios - Javanauta

Repositório criado para armazenar os exercícios e exemplos desenvolvidos durante o curso de Java da Javanauta.

O objetivo deste projeto é acompanhar minha evolução na linguagem Java por meio da resolução de exercícios e da prática dos conceitos apresentados ao longo do curso.

## Estrutura do projeto

```
src/
├── Aulas/        # Exemplos apresentados durante as aulas
└── Exercicios/   # Exercícios resolvidos
```

## Tecnologias

- Java
- Visual Studio Code
- Git
- GitHub

🚧 Em desenvolvimento
